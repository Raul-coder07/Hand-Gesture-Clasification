#Hand Gesture Classification from EMG Signals Using Deep Learning

This repository contains the source code developed for the project “Hand Gesture Classification from Electromyographic Signals Using Deep Learning”, whose main goal is to classify hand gestures from electromyographic (EMG) signals using deep learning models, while balancing classification performance and computational efficiency.

The project evaluates different convolutional architectures using EMG data acquired with sensors of different characteristics, including medical-grade systems and low-cost devices, under scenarios involving both an amputee subject and a healthy subject.

📌 Project Objective

The objective of this work is to develop and evaluate deep learning models capable of classifying hand gestures from EMG signals, focusing on:

High classification accuracy

Low inference time

Dataset Description

Three EMG datasets are used in this project:

Dataset 1

Sensor: BTS (medical-grade)

Subject: Amputee subject

Channels: 6

Sampling frequency: 1 kHz

Dataset 2

Sensor: MyoWare 2.0

Subject: Amputee subject

Channels: 4

Sampling frequency: 1 kHz

Dataset 3

Sensor: MyoWare 2.0

Subject: Healthy subject

Channels: 4

Sampling frequency: 1 kHz
